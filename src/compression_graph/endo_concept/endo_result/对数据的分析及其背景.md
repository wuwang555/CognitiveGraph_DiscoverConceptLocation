## 2. 关键决策

### 2.1 ! 三方法（不是两方法）

! **原摘要写"A = FP-Growth，B = 包含格"，需要修正。当前实现是三种真正独立的方法**，共享同一个幂集枚举，但过滤规则和参数完全独立：

| 方法 | 搜索空间 | 过滤规则 | 语义 | 参数前缀 |
|------|---------|---------|------|---------|
| **A** | 幂集 | `support ≥ θ_s` | **所有频繁项集**（宽谱） | `fp_*` |
| **B** | 幂集 | `support ≥ θ_s` + **下界** | **最小频繁项集**（不可再分） | `lattice_*` |
| **C** | 幂集 | `stability ≥ θ_role` + `support ≥ θ_aux` | **角色一致的项集**（功能单一） | `role_*` |

+ **三者的关系**：

- `A ⊇ B`：B 是 A 的子集（下界是 A 的特例）。
- `C` 与 `A/B` 独立：C 按角色稳定性筛选，不按支持度。
- `A ∩ C`：既频繁又角色稳定 → 最强的 fixpoint。
- **实测**：`C ⊂ B`，C 始终是 B 的严格子集。

+ **实际用途排序**：B、C 是分析主力；**A 更多是"穷举"**——它输出宽谱，用于对照和上界参考，但单独看信息密度低（含大量"高频+低频"的组合）。

### 2.2 ○ 分析视角从"共现"切换到"包含格"

○ 保留：需重点分析 **方法 B（包含格）**生成的数据。底元素 = 本质法则/基础基座，顶元素 = 综合应用/复合系统。

+ **补充 C 方法的视角**：C 不是另一个格，是**"角色纯的子集"**。C 的价值在于它给 B 提供了一个"功能一致性"的筛选——B 告诉你"什么是不可再分的"，C 告诉你"什么是不可再分且功能单一的"。

+ **C/B 比**是本项目**最重要的聚合指标**，见 §2.4。

### 2.4 + C/B 比的精确定义（原摘要缺失）

+ **这不是一个事后解释的指标，是从方法定义直接推出的本体论量**：

```
C/B = |{ s | s 稳定且角色纯 }| / |{ s | s 稳定 }|
    = "稳定单元里，角色纯的占比"
```

+ **从 B/C 到 C/B 的推导链**（纯逻辑，不依赖数据）：

1. B = 最小频繁项集 = 稳定且不可再分的单元。
2. C = B 中角色一致的那些 = 稳定且功能单一的单元。
3. 角色一致 ⇔ 在所有事件里功能不变 ⇔ **语境独立**。
4. C/B = 稳定单元里语境独立的占比。
5. 语境独立 = **本质主义**；语境依赖 = **关系主义**。
6. C/B = 概念集里"专才型原子"占"所有原子"的比例。

+ **一句话**：C/B 测量的是**概念集的分工结构**——专业化 vs 通用化。

### 2.5 + 三种"通用量"的本体论（B−C 的成员类型）

+ 三个数据集的 B−C（被 C 过滤掉的、角色混合的）成员性质不同：

| 数据集 | B−C 的类型 | 例子 | 哲学立场 |
|--------|-----------|------|---------|
| **A（跨领域）** | **领域性通用量** | 能量守恒、万有引力、算法、操作系统 | **关系主义**（意义由多领域关系定义） |
| **B（CS）** | **层次性通用量** | 面向对象、类型推断、闭包、有限状态机 | **功能主义**（意义由抽象-实现接口定义） |
| **C（数学）** | **构成性通用量** | 基、矩阵、自然数、极限、乘法 | **结构主义**（意义由在结构中的位置定义） |

+ **重要直觉**：你之前说的"数学的不动性催生很多概念"——这个"不动"**不是"角色纯"，是"角色混合"**。基础概念（集合、函数、极限）永远在场，要服务所有场景，所以角色必然混合。**"不动" = "被所有概念调用" = "角色混合"**。这修正了"稳定 = 角色纯"的直觉。

### 2.6 + 概念生成的边界（原摘要缺失）

+ **本项目当前做的不是"概念生成"，是"抓重点"**。真正的概念生成需要**三图架构**（属于后续工作）：

| 图 | 节点 | 边 | 状态 |
|----|------|----|----|
| **G1 能量图** | 原始概念 | 语义关联（认知能耗） | ✅ 原论文已有 |
| **G2 关系图** | 原始概念 | 共现次数（压缩统计） | ✅ 本项目已有 |
| **G3 生成图** | 不动点（G2 的 fixpoint） | 不动点之间的邻近/共现/边界耦合 | ❌ 后续工作 |

+ **为什么需要 G3**：不动点（如 `{唯一性, 连续性, 可微性}`）是**集合**，不是**节点**。把它们塞回 G1 是范畴错误——它们没有"毛边"（boundary/logic/energy），放进去要么坍缩（变成全局吸引子），要么无效（变成孤岛）。只有**把多个不动点连接起来**，给它们加上新的"毛边"，才能降级到 G1 的层级。

+ **"毛边"概念**：不动点本身没有毛边（boundary 大但 logic 弱），连接后产生新毛边（不动点之间的耦合）。**毛边 = 降级机制**。

+ **参数能否一致**：不是"必须等于 G1 参数"，而是"扰动可控"——让新概念放进 G1 时**不引起坍缩，也不等于没放**。物理类比：新概念的质量尺度不落在黑洞区间，也不落在虚空区间。

### 2.7 + 稳定性度量的修正（原摘要缺失）

! **原实现有 bug**：`S(x) = 1 − std(rank)/mean(rank)` 在 `mean(rank) → 0` 时爆炸——任何"偶尔做成员"的概念，S 就崩到 0，导致整组被否决。

+ **修复**：换成**角色一致性**：

```
role(x) = max(n_center, n_member) / (n_center + n_member)   ∈ [0.5, 1.0]
```

+ **性质**：全中心 → 1.0；全成员 → 1.0；50/50 → 0.5；对称、有界、无数值爆炸。

+ **这是方法论贡献**：原论文的位置稳定性在数值上不稳定；角色一致性是更稳健的替代。

## 5. + 分析框架的最终定位（原摘要缺失，但对多 AI 协作至关重要）

### 5.1 两个层次的分析

| 层次 | 做什么 | 输出 | 状态 |
|------|--------|------|------|
| **结构测量**（已完成） | 检测 fixpoint、计算 C/B、跑四类检验 | `fixpoints.json`、`endo_summary.csv`、`endo_eval` 报告 | ✅ |
| **语义赋予**（当前任务） | 给 fixpoint 写定义卡 | Concept Card | 🔄 |

### 5.2 语义赋予的证据链

每张定义卡必须能追溯到**三类证据**：

```
1. 结构证据：core / boundary / logic / energy / stability / method
                ↓
2. 统计证据：support / Φ / 是否 C 保留（角色纯）
                ↓
3. 外部证据：CONCEPT_DOMAINS 的领域标注 / META_STRUCTURE_MAP 的元结构
                ↓
4. 定义卡：名称 + 内涵 + 外延 + 为什么能压缩
```

**任何一项定义都不能脱离这四层证据**——这是"防止 LLM 凭空捏造"的工程约束。

### 5.3 底元素 vs 顶元素 vs 中间元素（B 方法的 Lattice 视角）

| 类型 | Lattice 位置 | 语义 | 定义模板侧重 |
|------|-------------|------|-------------|
| **底元素** | 最小下界（无频繁真子集） | 本质法则/基础基座 | **内涵与公理**：它是支撑外围词汇的底层基座 |
| **中间元素** | 有真子集也有真超集 | 中介/桥接 | **双向联系**：向下依赖什么，向上支撑什么 |
| **顶元素** | 最大上界（无频繁真超集） | 综合应用/复合系统 | **外延与集成**：它向下包含了哪些基础模块并实现功能统合 |

**判定规则**（补充）：

- `support` 高 + 无频繁真子集 → **底元素候选**。
- `support` 低 + 无频繁真超集 → **顶元素候选**。
- 方法 C 保留（角色纯）→ **更可能是底元素或顶元素**（中间元素通常是桥接的，角色混合）。
- 方法 B−C（角色混合）→ **更可能是中间元素或桥接**。

### 5.4 三个数据集的分析侧重

| 数据集 | 分析侧重 | 理由 |

## 7. 一句话总结（给多 AI 的定位）

**本项目做的是"抓重点"——从原论文一阶系统产生的压缩事件中，用三种独立方法（A 宽谱 / B 最小频繁 / C 角色纯）识别稳定单元（fixpoint），并用四类检验（稳定性差 + domain enrichment + 二项 + 轨迹）验证它们不是随机噪声。核心指标是 C/B（稳定单元里角色纯的占比，即"专才型原子"的比例），它从方法定义直接推出，不依赖事后解释。三个数据集（跨领域 / CS / 数学）给出三条不同轨迹（单调升 / U 型 / n 型），是三种"概念加入顺序"的直接反映。当前任务是把 B/C 方法的 fixpoint 转成概念定义卡，每张卡必须携带结构、统计、外部、定义四层证据。真正的"概念生成"（G3 架构）属于后续工作，不在本项目范围内。**
