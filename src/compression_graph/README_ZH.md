# 压缩关联图——二阶观察层

本模块**不修改**原论文的任何公设，也不改变 `CognitiveUniverseEnhanced`
的行为。它只做一件事：把原系统产生的**概念压缩事件**统计成一张
**无向加权图**，再在这张图上用与原论文一致的检测机制，检出
**压缩候选**与**迁移候选**。

## 核心思想

- 一次压缩事件 `(center, {members})` 视为一个无向团，
  团内所有无序对的共现次数 +1。
- 图是**无向**的。因为在单一静态语境下，我们无法判断一次
  压缩是"中心 → 成员"还是"成员 → 中心"。系统只记录
  "这些概念被压缩在一起过"这一事实。
- 边权 = **原始共现次数**。不做任何映射、不做成本、不做归一化。
- 检测机制与原论文一致：
  - **迁移**：先通过硬遍历、软遍历产生遍历历史；一条路径
    的平均共现次数超过**绝对阈值**，就记为一次迁移候选。
  - **压缩**：对每个节点作为中心，取其 top-k 邻居构成簇；
    压缩势 Φ = 内部平均共现 / 外部平均共现，超过**绝对阈值**
    就记为一次压缩候选。
- 检测结果是**候选概念**，在单一静态语境下它们无法被外部
  校准，因此只是统计假设。

## 为什么设计这么简单

- **绝对阈值**：不用百分位，让不同规模之间可比。
- **不做剪枝**：搜索在完整图上进行，与原文一致。
- **不做社区检测**：那不是原论文的机制。
- **不做成本映射**：边权就是共现次数，不翻译成能量。
- **不做改善比**：原文的迁移判据里没有这一项。
- **不做子集/路径去重**：现实中压缩本就是多粒度的，
  子集关系保留下来更贴近静态语境下的真实认知状态。

## 入口

    python compression_graph/run_static.py

## 输出

`results/compression_graph/` 目录下：

- `pipeline_scale{N}.json` — 各规模的完整分析
- `graph_scale{N}.png` — 压缩关联图
- `edge_dist_scale{N}.png` — 边共现分布
- `migrations_scale{N}.png` — top 迁移路径高亮

CSV 表格：

- `summary.csv`                   — 每规模汇总
- `raw_compression_events.csv`    — 原始压缩事件
- `compression_edges.csv`         — 压缩关联图的每条边
- `candidate_compressions.csv`    — 压缩候选（候选概念-压缩型）
- `candidate_migrations.csv`      — 迁移候选（候选概念-迁移型）

### 各表字段

**summary.csv**

| 列 | 含义 |
|----|------|
| `scale` | 概念规模 |
| `n_raw_compression_events` | 原始压缩事件数（去重前） |
| `n_graph_nodes` | 图节点数 |
| `n_graph_edges` | 图边数 |
| `edge_count_max` | 最大共现次数 |
| `edge_count_mean` | 平均共现次数 |
| `n_candidate_compressions` | 检测到的压缩候选数 |
| `n_candidate_migrations` | 检测到的迁移候选数 |

**raw_compression_events.csv**

| 列 | 含义 |
|----|------|
| `scale` | 概念规模 |
| `event_id` | 事件序号 |
| `detection_iteration` | 检测发生的迭代步 |
| `center` | 检测器选出的中心节点 |
| `cluster_size` | 簇大小 |
| `related_nodes` | 相关节点（竖线分隔） |
| `emergence_strength` | 原检测器给出的综合强度 |

**compression_edges.csv**

| 列 | 含义 |
|----|------|
| `scale` | 概念规模 |
| `concept_a` | 概念 A |
| `concept_b` | 概念 B |
| `count` | A、B 一起被压缩的次数 |

**candidate_compressions.csv**

| 列 | 含义 |
|----|------|
| `scale` | 概念规模 |
| `rank` | 按 Φ 降序的排名 |
| `center` | 中心节点 |
| `cluster` | 簇内所有概念（竖线分隔） |
| `size` | 簇大小 |
| `phi` | 压缩势 Φ = 内部平均共现 / 外部平均共现 |

**candidate_migrations.csv**

| 列 | 含义 |
|----|------|
| `scale` | 概念规模 |
| `rank` | 按平均共现降序的排名 |
| `length` | 路径节点数 |
| `start` | 起点 |
| `end` | 终点 |
| `path` | 完整路径（箭头分隔） |
| `score` | 路径平均共现次数 |

## 与原论文的关系

| 原论文 | 本模块 |
|--------|--------|
| 认知图上的能量 | 压缩图上的共现次数 |
| 硬遍历 / 软遍历 | 压缩图上的硬遍历 / 软遍历 |
| 通过原理节点的迁移 | 通过中间路径的迁移 |
| 压缩势 Φ | Φ = 内部平均 / 外部平均 |
| 中心节点频率 Zipf | 压缩边共现频率 Zipf |
| —— | 候选概念统计 |

## 重要说明

- 候选是**假设**，不是已验证的概念。在单一静态语境下
  无法被外部校准，需要人工审阅、命名或下游任务检验。
- 本模块**不回填**原论文的图。回填（图2 产出进入图1）
  属于动态版本，将在后续交付。
- 本模块**不做**任何"工程化"的化简：不做剪枝、不做
  百分位阈值、不做社区检测、不做成本映射、不做改善比。
  这些决策是为了保持与原论文一致的简洁性，也为了让
  "静态语境下无外部校准"这一假设在数据里如实呈现。
