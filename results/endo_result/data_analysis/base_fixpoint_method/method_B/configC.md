# config_C 四 scale 综合分析（方法 B）：前缀结构与五层存活模型

> 把 51/71/91/111 放回 config.py 的 `CORE_CONCEPT_DEFINITIONS_C` 定义顺序里看，会发现之前四个 scale 的"域切换"其实是一个**前缀扩张**过程，而不同域在 fixpoint 里的"存活模式"截然不同。这是四 scale 分析里之前没有统一的视角，下面补上。

---

## 一、核心发现：四个 scale 是"前缀"，不是"随机切片"

config.py 里 `CORE_CONCEPT_DEFINITIONS_C` 的定义顺序是：

```
1–20   逻辑与集合论（20）
21–30  数系（10）
31–40  代数（10）
41–66  分析（26）
67–91  几何（25）
92–101 拓扑（10）
102–111 数论（10）
112–120 应用数学（9）
```

**四个 scale 恰好是这条顺序的前缀**：

| scale | 前缀构成 | 域组合 |
|-------|---------|--------|
| **51** | 1–51 | 逻辑20 + 数系10 + 代数10 + **分析前11** |
| **71** | 1–71 | 逻辑20 + 数系10 + 代数10 + **分析26** + **几何前5** |
| **91** | 1–91 | 逻辑20 + 数系10 + 代数10 + 分析26 + **几何25** |
| **111** | 1–111 | 逻辑20 + 数系10 + 代数10 + 分析26 + 几何25 + **拓扑10** + **数论10** |

**这不是"同一概念集规模递增"，而是"按定义顺序逐步加入新域"**。所以 51→71→91→111 的差异，本质上是"新域加入对既有 fixpoint 格局的扰动"。

**这个视角修正了前面四个 scale 分析里的一个隐含假设**：之前我把 51/71/91 当成"三个不同采样"，现在看它们是"同一概念集的四个前缀"。n_events 的 952→732→332→577 不是"采样波动"，而是**"概念集前缀长度"对压缩事件量的影响**——前缀越长，事件越稀疏（91 最短），但 111 加入拓扑/数论后事件回升，说明新域的加入"重新激活"了系统。

## 二、按域拆解：五种截然不同的"存活模式"

把每个 scale 的 fixpoint 按"它属于前缀的哪一段"归类，得到五种存活模式：

### 2.1 背景层：逻辑与集合论（1–20）——**从不存活**

| scale | 逻辑与集合论的 fixpoint |
|-------|----------------------|
| 51 | **0/20** |
| 71 | **0/20** |
| 91 | **0/20** |
| 111 | **0/20** |

**四个 scale、四遍、一个都没有**。命题、集合、函数、等价关系、偏序、幂集、笛卡尔积——全部不在 fixpoint 列表里。

**这是四 scale 分析里最稳定的"负结果"**：逻辑与集合论是概念集的**元层**（所有概念的容器），它们在压缩事件里作为"背景"出现在几乎所有事件中，所以**永远不构成"最小频繁项集"**——它们不是"特定组合"，而是"普遍背景"。这与《交接摘要》§2.5 的"不动 = 角色混合 = 被所有概念调用"完全一致，但**逻辑与集合论把这个机制推到了极限**：角色混合到"无法成为任何一个最小频繁项集的成员"。

**与数系的对照**：数系也是"被广泛调用"的基础，但数系是 10/10 成为 fixpoint。区别在于：**数系概念是"对象层"的独立原子**（自然数本身是独立对象，加法本身是独立操作），**逻辑概念是"元层"的容器**（集合不是对象，是所有对象的容器）。**压缩机制识别的是"对象层的稳定单元"，不是"元层的容器"**——这是方法 B 的一个方法论边界。

### 2.2 恒核层：数系（21–30）——**10/10 恒定**

| scale | 数系的 fixpoint | 具体 |
|-------|---------------|------|
| 51 | **10/10** | 自然数、整数、有理数、实数、复数、序、加法、乘法、减法、除法 |
| 71 | **10/10** | 同上 |
| 91 | **10/10** | 同上 |
| 111 | **10/10** | 同上 |

**四 scale、四遍、十个成员完全一致，一个不多一个不少**。数系是概念集里**唯一的绝对不变量**。

**为什么数系能恒定存活？** 三个原因：
1. **原子性**：每个数系概念都是"不可再分的最小单位"（自然数不能分成更小的数系概念）。
2. **独立性**：10 个概念彼此是"并列关系"（自然数/整数/有理数/实数/复数 是嵌套，加法/乘法/减法/除法 是并列），没有"包含"关系，所以每个都能独立成为"最小频繁项集"。
3. **高频性**：数系是数学的"通用语言"，在几乎所有压缩事件里都出现，但出现的方式是"作为独立操作/对象"，不是"作为背景"。

**数系是方法 B 下"最理想的 fixpoint 形态"**：原子、独立、高频、角色清晰。

### 2.3 浮动层：代数（31–40）——**前中期满，后期被挤压**

| scale | 代数的 fixpoint | 具体 |
|-------|---------------|------|
| 51 | **10/10** | 群、环、域、向量空间、线性映射、矩阵、基、维数、线性无关、线性组合 |
| 71 | **10/10** | 同上 |
| 91 | **10/10** | 同上 |
| **111** | **3/10** | **只剩线性组合、维数、线性无关** |

**代数在 51/71/91 是完整层，111 急剧缩到 3 个**。这是一个非常干净的"挤压"模式：当拓扑（92–101）和数论（102–111）加入后，代数的 7 个成员（群、环、域、向量空间、线性映射、矩阵、基）**不再成为 fixpoint**。

**为什么被挤压？** 合理的解释是：**这 7 个概念是"复合结构"**——群 = 集合 + 运算 + 三公理，环 = 群 + 第二运算，向量空间 = 域 + 加法群 + 标量乘，矩阵 = 向量空间的表示。当拓扑/数论加入后，它们的事件里包含了更多的"原子化"概念（开集、闭集、素数、整除），这些新概念**在压缩事件中"抢走"了代数的复合结构的位置**——压缩机制倾向于选择"更小的、更原子的"稳定单元。**代数的抽象结构被"分解"成了更细的概念**。

**代数的"三人小三角"（线性组合、维数、线性无关）在 111 存活，且 energy 跌到 11–22**：这三个是代数里最"原子"的概念（线性组合 = 向量的叠加，维数 = 基的个数，线性无关 = 无平凡零组合），它们不是"复合结构"，所以能存活。但它们只彼此相连，形成一个封闭的"三人小三角"——这是"被挤压到只剩原子核心"的典型形态。

### 2.4 浮动层：分析（41–66）——**短暂存活，迅速退场**

| scale | 分析的 fixpoint | 具体 |
|-------|---------------|------|
| **51** | **11/26** | 序列、极限、连续性、可数、不可数、上确界、下确界、开区间、闭区间、邻域、度量空间（分析的前 11 个） |
| **71** | **1/26** | 只剩巴拿赫空间（分析的最后 1 个） |
| 91 | **0/26** | — |
| 111 | **0/26** | — |

**分析是"加入后迅速退场"的典型**：51 时前 11 个是 fixpoint，71 时只剩最后 1 个，91 后全没。

**注意"前 11 个"和"最后 1 个"这个细节**：51 的 fixpoint 是分析的前 11 个（序列...度量空间），71 的 fixpoint 是分析的最后 1 个（巴拿赫空间）。**中间的 14 个（导数、微分、积分、级数、收敛、一致连续、可微、可积、泰勒展开、傅里叶变换、微分方程、偏微分方程、范数、内积）从来没有成为过 fixpoint**。

**这意味着分析域内部有清晰的分裂**：
- **前置层**（序列、极限、连续性、区间、确界、邻域、度量空间）：在 51 是 fixpoint，71 后退场。
- **中段**（导数、积分、级数、泰勒展开、傅里叶变换、微分方程...）：**从来没成为 fixpoint**。
- **末端**（巴拿赫空间）：在 71 是 fixpoint，51 和 91 都不是。

**分析的中段"从来不存活"** 是一个重要发现——这些是分析里"最复合"的概念（导数 = 极限 + 微分，积分 = 极限 + 求和，微分方程 = 导数 + 方程），它们太复合，无法成为"最小频繁项集"。**分析的前置层（序列、极限）是"原子"的，所以能短暂存活；中段是"复合"的，所以从不存活；末端（巴拿赫空间）是"完备赋范向量空间"，是"代数 + 分析"的跨界点，偶尔存活。**

### 2.5 浮动层：几何（67–91）——**短暂存活，迅速退场**

| scale | 几何的 fixpoint | 具体 |
|-------|---------------|------|
| 51 | 0/25（未加入） | — |
| **71** | **5/25** | 欧氏空间、点、线、面、距离（几何的前 5 个） |
| **91** | **1/25** | 只剩欧氏空间 |
| **111** | **0/25** | — |

**几何比分析"更短暂"**：71 时 5 个，91 只剩 1 个，111 完全消失。

**"前 5 个"这个细节同样关键**：71 的几何 fixpoint 是几何的前 5 个（欧氏空间、点、线、面、距离），这正是 71 前缀里"几何的部分"（67–71）。**当 91 几何完整加入后，只有欧氏空间 1 个存活，其余 4 个（点、线、面、距离）全退场**。

**这是一个"加入即解体"的典型**：71 时几何只有 5 个，它们作为"新进入的集团"整体存活；91 时几何完整加入（25 个），5 个里有 4 个被"稀释"退场，只剩欧氏空间（因为它已经"代数化"了——91 的欧氏空间 boundary 全是代数概念）。

**几何的"集团性"是双刃剑**：71 时 5 个一起存活（强耦合集团，logic 0.79–1.0），91 时集团解体只剩 1 个。**集团在"小规模"时稳定，在"大规模"时解体**——这与拓扑在 111 的"9 个整块存活"形成对比（见下）。

### 2.6 末端稳定层：拓扑（92–101）+ 数论（102–111）——**加入后整块存活**

| scale | 拓扑 fixpoint | 数论 fixpoint |
|-------|-------------|-------------|
| 51 | 未加入 | 未加入 |
| 71 | 未加入 | 未加入 |
| 91 | 未加入 | 未加入 |
| **111** | **9/10**（缺同调） | **10/10** |

**111 是拓扑和数论的首次进入，两者几乎整块成为 fixpoint**。这与分析/几何的"加入后迅速退场"形成鲜明对比。

**为什么拓扑/数论能整块存活？** 它们的概念是"公理化的原子"：
- **数论**：素数、合数、整除、模运算、最大公约数、最小公倍数、同余、欧拉函数、费马小定理、黎曼假设——每个都是"独立的数论对象/性质"，彼此是"并列/派生"关系，没有"包含"关系。
- **拓扑**：开集、闭集、连续映射、同胚、连通、紧致、豪斯多夫空间、基本群、覆叠空间——每个都是"通过公理定义的拓扑对象"，彼此是"并列/派生"关系。

**这与数系的"原子性"同构**：数论和拓扑的概念都是"原子化"的，不是"复合结构"（不像代数里的群=集合+运算，不像分析里的导数=极限+微分）。**原子性 = 能成为 fixpoint**。

**拓扑的"强耦合集团"结构（logic 大量 1.0）**：9 个拓扑成员里，闭集和连续映射是"角色混合"的（stability 0.642），其余 7 个是"角色纯"的（1.0）。这与 71 几何的"线/面是通用量、点/距离是专才"结构一致——**每个强耦合集团里总有 1-2 个"粘合剂"（角色混合）和若干"专才"（角色纯）**。

## 三、五层存活模型：一张图概括四 scale

把上面六种模式归并，得到 config_C 的"五层存活模型"：

```
┌─────────────────────────────────────────────────────────────┐
│ 第 0 层：背景层（逻辑与集合论，1–20）                          │
│   存活模式：从不存活（0/20 × 4 scale）                         │
│   原因：元层容器，角色混合到无法成为最小频繁项集                 │
├─────────────────────────────────────────────────────────────┤
│ 第 1 层：恒核层（数系，21–30）                                 │
│   存活模式：10/10 恒定（4 scale 完全一致）                     │
│   原因：原子、独立、高频、角色清晰                              │
├─────────────────────────────────────────────────────────────┤
│ 第 2 层：浮动层（代数 31–40 / 分析 41–66 / 几何 67–91）         │
│   存活模式：随 scale 浮动                                     │
│   ├─ 代数：10→10→10→3（前中期满，后期被挤压）                  │
│   ├─ 分析：11→1→0→0（短暂存活，迅速退场；中段从不存活）         │
│   └─ 几何：—→5→1→0（加入即解体；前 5 个短暂存活）              │
│   原因：中间结构，会被新域的"原子化"概念挤压                    │
├─────────────────────────────────────────────────────────────┤
│ 第 3 层：末端稳定层（拓扑 92–101 / 数论 102–111）              │
│   存活模式：加入后整块存活（111：拓扑 9/10，数论 10/10）        │
│   原因：公理化的原子，不是复合结构                              │
├─────────────────────────────────────────────────────────────┤
│ 第 4 层：未加入（应用数学 112–120）                            │
│   本批数据未涉及                                               │
└─────────────────────────────────────────────────────────────┘
```

**这个模型的核心断言**：

1. **"越基础越稳定"是错的**——逻辑与集合论是最基础的，却从不存活。
2. **"越具体越稳定"也是错的**——应用数学（未加入）未必稳定；分析和几何是"具体"的，却在中间层浮动。
3. **真正的稳定判据是"原子性"**——数系、数论、拓扑的概念是"原子"的（不可再分、独立、并列），所以稳定；代数、分析、几何的很多概念是"复合"的（可分解为更小的概念），所以浮动。

**这个"原子性判据"可以解释所有现象**：
- 数系 10/10：全部原子。
- 数论 10/10、拓扑 9/10：全部原子。
- 代数 10→3：前 10 个里，群/环/域/向量空间/矩阵/基是复合结构（被挤压），线性组合/维数/线性无关是原子（存活）。
- 分析 11→1→0：前 11 个（序列/极限/区间/确界/邻域）是原子，中段 14 个（导数/积分/级数）是复合，末端巴拿赫空间是跨界点。
- 几何 5→1→0：前 5 个（点/线/面/距离/欧氏空间）是原子，后面 20 个（流形/切空间/曲率/测地线）是复合。

**这是一条统一的结构规律，比"域切换"更根本**。

## 四、用五层模型重解 C/B 的 n 型轨迹

之前我把 C/B 的 n 型（0.516→0.577→0.762→0.656）解释为"域代际更替时的角色混合程度"。用五层模型可以更精确地重解：

| scale | 当前活跃层 | C/B | 五层模型解释 |
|-------|-----------|-----|-------------|
| **51** | 恒核 + 代数 + **分析前置(11)** | 0.516 | 分析前置 11 个里，**序列/极限/连续性/可数/不可数/开区间/闭区间/邻域/度量空间** 多数是角色混合的（stability 0.597–1.0，其中 4 个 < 0.87），拉低 C/B |
| **71** | 恒核 + 代数 + 分析 + **几何前 5** | 0.577 | 几何前 5 个里，**点/欧氏空间/距离** 角色纯（1.0），**线/面** 角色混合（0.771），整体拉高 C/B |
| **91** | 恒核 + 代数（**浮动层收缩**） | 0.762 | 分析和几何的浮动层退场，只剩恒核+代数，而代数的 10 个里多数在 91 角色纯（0.925–1.0），所以 C/B 最高——**这是"浮动层退场导致的假性高峰"** |
| **111** | 恒核 + **末端稳定层（拓扑+数论）** + 代数残三角 | 0.656 | 拓扑/数论的"公理原子"里，**合数/素数/最大公约数/闭集/连续映射/同余** 等是角色混合的（0.556–0.781），拉低 C/B |

**修正后的结论**：C/B 的 n 型不是"层级深度"，也不是简单的"域代际更替"，而是**"当前活跃层中'公理原子但角色混合'的概念比例"**：
- 51：分析前置（原子但多数混合）→ 低
- 71：几何前 5（混合少）→ 中
- 91：浮动层退场，只剩恒核+代数（几乎全角色纯）→ 高
- 111：拓扑/数论（原子但基础概念混合）→ 回落

**91 的 0.762 是"浮动层退场"的产物，不是"结构最优"**。这一点在四 scale 分析里已经提示过，现在有了更精确的机制解释。

## 五、方法 B 下 config_C 的总特点（五条）

综合四 scale，方法 B 在 config_C 上呈现五个稳定特点：

1. **"原子性"是 fixpoint 的唯一判据**：能成为 fixpoint 的，都是"不可再分、独立、并列"的原子概念；复合结构（群/环/导数/流形）会被挤压或从不存活。数系、数论、拓扑是"全原子层"，所以稳定；代数、分析、几何是"半复合层"，所以浮动。

2. **"元层永不存活"**：逻辑与集合论（集合、函数、关系、偏序）是"元层容器"，在所有 scale 都 0/20。**方法 B 的 fixpoint 只在"对象层"出现，不在"元层"出现**——这是方法 B 的一个硬边界，不是数据缺陷。

3. **"恒核 + 末端稳定"是两极，中间是浮动带**：数系（恒核）和拓扑/数论（末端稳定）是概念集的两极稳定层，代数和分析/几何是中间的浮动带。**概念集不是"金字塔"，是"哑铃"**——两头稳，中间晃。

4. **C/B 是"活跃层角色混合比例"的间接测量**：0.516/0.577/0.762/0.656 的 n 型，对应"分析前置活跃→几何前 5 活跃→浮动层退场→拓扑/数论活跃"的四个阶段，不是"层级深度"也不是"好坏"。**统一阈值 0.86 四次精确复现**，是框架最硬的可复现性证据。

5. **"不动 = 角色混合"在每个域都有具体化身**：51 的代数核心（基/矩阵 support 高 stability 低）、71 的几何通用量（线/面 0.771）、91 的线性无关（0.550）、111 的拓扑粘合剂（闭集/连续映射 0.642）和数系撕裂点（自然数 0.556）。**每个域的"定义基础"都是角色混合的，每个域的"末端专才"都是角色纯的**。

## 六、实际意义（限定方法 B + config_C）

按你最初的目标（"为复合概念群自动赋予人类可理解的实际意义，产出概念定义卡"），这个分析给出四个直接可用的工程结论：

### 6.1 概念卡分配的"优先级地图"

## 一、哲学意义：从"结构主义"重读四 scale

《交接摘要》§2.5 给 C 数据集定的哲学立场是**结构主义**（意义由在结构中的位置定义）。四 scale 的数据不仅支持这个判断，还给出了比"结构主义"更精确的三层结构。

### 1.1 结构主义不是"本质固定"，是"位置由结构决定"

四 scale 里，数系的 10 个成员**完全不变**（自然数、整数、有理数、实数、复数、序、加法、乘法、减法、除法）。如果按本质主义读，这 10 个概念"本质上就是它们自己"，所以稳定。

但数据给出的是另一个故事：**它们"稳定"是因为它们"在每个 scale 的结构里都有位置"**——不是"位置不变"，是"总有一个位置"。51 里自然数连着 7 个数系概念（减法/加法/复数/实数/整数/有理数/除法），111 里只连着 3 个（乘法/实数/有理数）。**自然数本身没变，但它所在的"结构网络"变了，所以它的"位置"变了**。

**这是结构主义的强形式**：**概念的意义不是固有属性，是"它在当前结构网络中的位置"**。当结构变（scale 变），位置变，意义变。数系的"恒定"不是"位置恒定"，是"在每个结构里都能找到一个位置"。

### 1.2 "不动 ≠ 角色纯"的哲学深度：能指稳定，所指漂移

《交接摘要》§2.5 的核心直觉是"数学基础概念不动，是因为被所有概念调用，角色必然混合"。四 scale 数据把这个直觉推进了一层：

- **自然数"不动"**（四个 scale 都存活，是唯一跨 scale 恒定层的一员）——它是**能指**（signifier），符号"自然数"始终在。
- **但自然数的"角色"在每个 scale 都不同**：51 里服务减法/加法/除法，111 里被乘法"吸附"（乘法 logic=0.947，energy=143，是它最强的邻居）。它的**所指**（signified）在漂移。

**"不动"是符号的稳定，"角色混合"是所指的漂移**。这正是结构主义-后结构主义的经典判断：**能指链是稳定的，但所指永远在滑动**。四 scale 数据给了这个哲学判断一个可量化的证据。

### 1.3 C/B 的 n 型 = "位置确定性"，不是"本质/关系比例"

《交接摘要》§2.4 说 C/B 测量"语境独立 = 本质主义；语境依赖 = 关系主义"。四 scale 数据要求修正这个二分：

| scale | C/B | 结构状态 | 位置确定性 |
|-------|-----|---------|-----------|
| 51 | 0.516 | 分析前置 11 个进入，结构扩张 | 低（新成员位置未定） |
| 71 | 0.577 | 几何前 5 个进入，结构再扩张 | 中（几何集团内部位置清晰） |
| 91 | 0.762 | 浮动层退场，结构收窄 | **高（每个概念位置固定）** |
| 111 | 0.656 | 拓扑/数论整块进入，结构再扩张 | 低（新成员位置未定） |

**C/B 不是"本质主义/关系主义"的比例，而是"结构收缩/扩张时，概念位置确定性"的测量**。91 的 0.762 是"结构最窄、位置最确定"的峰值——不是"更本质"，是"更窄"。111 的 0.656 是"结构扩张、位置未定"的回落——不是"更关系"，是"更宽"。

**这修正了哲学解读**：C/B 测的不是"概念自身的本质性"，是"概念在当前结构里的位置确定性"。结构越窄，位置越确定，C/B 越高；结构越宽，位置越模糊，C/B 越低。**C/B 的 n 型 = 结构的"宽-窄-宽"呼吸**。

### 1.4 方法论边界的哲学意义：方法 B 只测"对象层结构位置"

逻辑与集合论（20 个概念）在四个 scale 全部 **0/20**。这不是数据缺陷，是方法 B 的**硬边界**：**fixpoint 识别只在"对象层"有效，不在"元层"有效**。

哲学上，这意味着：**方法 B 测量的是"对象在结构中的位置"，不是"元层对结构的定义"**。集合、函数、关系是"结构的容器"（它们定义了什么是一个结构），所以它们**不在结构里，而是结构本身**——压缩机制无法把它们识别为"结构里的一个单元"。

**这条边界有哲学分量**：结构主义说"意义由结构中的位置定义"，但**结构本身的定义（元层）不在这个测量范围内**。方法 B 能测"对象层结构主义"，不能测"元层结构主义"。这是方法 B 的**本体论盲区**，不是技术缺陷。

## 二、现实意义（限定方法 B + config_C）

### 2.1 概念卡设计原则的三条修正

- **能预测哪些概念不值得配卡**：分析中段 14 个（导数/积分/级数/泰勒/傅里叶/微分方程/偏微分方程/范数/内积/收敛/一致连续/可微/可积/偏微分方程）从未成为 fixpoint，几何后 20 个（流形/切空间/曲率/测地线/辛结构/联络/微分形式）也从未——**这些概念的"定义卡"不能从 fixpoint 数据里得到证据，需要另找证据来源**。

### 2.3 G3 接口的优先级：优先选"真专才"，避开"被吸附"

如果要为后续 G3（概念生成）准备"可安全嵌入的新节点"，五层模型给出优先级：

| 优先级 | 类型 | 111 的例子 | 理由 |
|--------|------|-----------|------|
| **高** | **真专才**（boundary 窄 + support 低 + stability=1.0 + 与邻居 logic 平衡） | 线性无关（boundary 3，support 0.036，stability 1.0） | 位置清晰，嵌入不引发坍缩 |

## 三、单样本合理性检验：抽"自然数"（111）

**为什么抽自然数**：它是四 scale 唯一"绝对恒核"的成员之一，却在 111 的 stability 是全数系最低（0.556）——**反差最大，最适合检验"不动 ≠ 角色纯"的判据**。

### 3.1 四 scale 的自然数数据

| scale | boundary | support | stability | 最强邻居（logic） |
|-------|---------|---------|-----------|------------------|
| 51 | 7 个（减法/加法/复数/实数/整数/有理数/除法） | 0.262 | 0.627 | 实数 0.876 |
| 71 | 7 个（同 51） | 0.359 | 0.654 | 实数 0.886 |
| 91 | 7 个（乘法/加法/复数/实数/整数/有理数/除法） | 0.560* | 0.747 | 实数 0.848 |
| **111** | **3 个（乘法/实数/有理数）** | 0.262 | **0.556** | **乘法 0.947** |

*91 的 support 0.560 是"分母效应"（n_events=332），不可与 51/71/111 的绝对值直接比，见 91 分析 §1。

### 3.2 合理性检验：111 的自然数"正常吗"？

**正常，且高度自洽**。三个证据：

**证据 1：boundary 收缩与 stability 降低同时发生，且方向一致。**

111 的自然数 boundary 从 7 缩到 3（加法、减法、除法、整数、复数 5 个邻居消失），同时 stability 从 0.747 跌到 0.556。这不是矛盾——**boundary 窄不等于角色纯**。51 时自然数在 7 个数系概念里"均匀分布"（与减法 0.612、加法 0.650、除法 0.654、整数 0.570、复数 0.707 都有中等 logic），角色虽混合但"分布均匀"，stability 0.627 是"均匀混合"。111 时只剩下乘法（0.947）、实数（0.815）、有理数（0.689）三个邻居，**乘法的 logic 0.947 是压倒性的**——自然数被乘法"吸附"了，它的"位置"从"数系网络的一个节点"变成"乘法的定义域"。**这是位置模糊，不是角色纯**。

**证据 2：与 111 的"真专才"形成干净对照。**

| 概念 | boundary 数 | support | stability | 最强邻居 logic | 判断 |
|------|------------|---------|-----------|---------------|------|
| **线性无关** | 3（域/线性组合/维数） | 0.036 | **1.0** | 线性组合 1.0、维数 1.0（**两个并列**） | **真专才**：与两个邻居等强，位置平衡 |
| **自然数** | 3（乘法/实数/有理数） | 0.262 | **0.556** | 乘法 0.947、实数 0.815、有理数 0.689（**梯度陡**） | **被吸附**：乘法压倒，位置失衡 |
| **合数** | 6（整除/最大公约数/模运算/欧拉函数/素数/费马小定理） | 0.350 | 0.609 | 素数 0.797、整除 0.723（**多邻居中等**） | **多邻居混合**：不是被吸附，是"多线程" |

**三者 boundary 都窄（3–6），但 stability 完全不同（1.0 / 0.556 / 0.609）**。判据不是"boundary 大小"，是**"与邻居的 logic 分布是否平衡"**：
- 平衡（线性无关：两个 1.0 并列）→ 专才。
- 梯度陡（自然数：0.947 / 0.815 / 0.689）→ 被吸附。
- 多邻居中等（合数：6 个 0.6–0.8）→ 多线程混合。

**证据 3：自然数的"对象 vs 操作"双重身份解释了撕裂。**

111 的数系 10 个成员里，**操作类**（乘法 0.957、加法 0.967、减法 0.819、除法 0.727）stability 普遍高，**对象类**（自然数 0.556、实数 0.591）stability 普遍低。原因：**操作总是做"中心"（它是动词），对象总是做"成员"（它是名词）**。但自然数有"双重身份"——它既是"乘法的输入"（做成员），又是"数论的研究对象"（111 里数论整块进入，自然数作为"素数/合数/整除"的基底，做中心）。**双重身份 = 角色撕裂 = stability 0.556**。

**这解释了为什么自然数在 111 恶化**：111 是数论整块进入的 scale，而数论的全部概念（素数/合数/整除/模运算/最大公约数/最小公倍数/同余/欧拉函数/费马小定理/黎曼假设）**都以自然数为基底**。自然数在 111 同时服务"数系内部操作"和"数论基底"两个结构，位置必然模糊。

### 3.3 检验结论

**自然数（111）的数据合理、自洽、且提供了一条可推广的判据**：

1. **"不动 ≠ 角色纯"在自然数上得到最强验证**：它是四 scale 恒核，但 111 的 stability 是全数系最低（0.556）。
2. **"boundary 窄 ≠ 专才"被证伪，正确判据是"logic 分布平衡"**：线性无关（两个 1.0 并列，stability 1.0）是真专才；自然数（0.947/0.815/0.689 梯度陡，stability 0.556）是被吸附。
3. **"操作 vs 对象"是 stability 分化的结构性原因**：操作（乘法/加法）做中心，对象（自然数/实数）做成员；对象有"双重身份"时（自然数 = 操作输入 + 数论基底），角色撕裂。
4. **这修正了《交接摘要》§2.5 的"不动 = 被所有概念调用 = 角色混合"**：更精确的说法是——**"不动" = "在不同结构里被不同邻居吸附"**。51 的自然数被 7 个邻居均匀调用（均匀混合），111 的自然数被乘法吸附（梯度混合）。两者都是"角色混合"，但机制不同：前者是"多线程"，后者是"被绑架"。

## 四、一句话总结

**从哲学上看，config_C 四 scale 是结构主义的强证据：概念的意义由"它在当前结构网络中的位置"定义，不是固有属性；数系 10 个"恒定"不是"位置不变"，是"在每个结构里都能找到位置"；"不动 ≠ 角色纯"的精确表述是"能指稳定、所指漂移"——自然数符号始终在，但它在 51 服务 7 个数系邻居、在 111 被乘法吸附（logic 0.947），所指在滑动；C/B 的 n 型不是"本质/关系比例"，是"结构收缩/扩张时位置确定性"的测量，91 的 0.762 是"结构最窄"的假性高峰，不是"最优"；方法 B 的"元层 0/20"是本体论盲区——它只测"对象在结构中的位置"，不测"元层对结构的定义"。从现实上看，这给出三条工程修正（基础概念必须写"位置"不能只写"本质"、boundary 窄 ≠ 专才要看 logic 分布是否平衡、C/B 只能描述结构状态不能评价质量）、一条可预测规则（给定前缀能预测哪些域存活）、和一条 G3 优先级（优先"真专才"如线性无关，避开"被吸附"如 111 的自然数）。单样本抽"自然数"检验完全合理：它四 scale 恒核但 111 的 stability 全数系最低（0.556），boundary 从 7 缩到 3 的同时与乘法 logic 0.947 形成"被吸附"——与"真专才"线性无关（boundary 3、support 0.036、两个 1.0 并列、stability 1.0）形成干净对照，证明判据不是"boundary 大小"而是"logic 分布是否平衡"；更深一层，111 是数论整块进入的 scale，自然数同时服务"数系内部操作"和"数论基底"两个结构，双重身份导致角色撕裂——这正是结构主义"位置决定意义"的终极例证。**
