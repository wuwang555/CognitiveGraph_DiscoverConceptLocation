# CognitiveGraph_DiscoverConceptLocation
# 认知图论：从二阶观察到四维概念空间

> 本项目承接《The Geometry, Algebra, and Dynamics of Cognition: A Unified
> Graph Theory Model Based on the Principle of Minimum Energy Consumption》
> （以下称"原论文"）的一阶认知图模型，在其之上构建**二阶观察层**：从
> 系统自发生成的概念压缩事件中，识别稳定结构，将其映射到连续的四维
> 概念空间，并对"概念区域的凸性"这一经验假设做一次可操作的检验。
>
> 本项目的基调与原论文一致：**不追求拟合，只追求可算**。每一环都明确
> 声明"这一环做什么"与"这一环观察到了什么"，并在结论处标注边界。
>
> 本仓库只做**抓重点**：从压缩事件中识别系统反复关注的稳定单元，并赋予
> 结构化定义。它不做另一个项目里的"让不动点成为新节点、构造更高层图、
> 再压缩/迁移降层级"。`endo_concept` 这个模块名虽然叫"内生概念生成"，
> 但在本仓库范围内，它仍然是抓重点，不是概念生成图构造。

---

## 一、我们不做的事

在开始之前，先划清范围。本项目**不做**以下事情：

- **不做概念生成**。本项目做的是"抓重点"——从压缩事件中识别系统
  反复关注的最小稳定单元（fixpoint），并为其赋予结构化定义。真正的
  "概念生成"（让不动点成为新节点、构造更高层的图）属于后续工作，
  不在本项目范围内。
- **不做工程化改造**。不对一阶系统做剪枝、百分位阈值、社区检测、
  成本映射。所有阈值保持绝对值，所有关系保持原样，所有多粒度输出
  （子集、路径、重复）都被保留。
- **不做实证拟合**。本项目不与人脑行为数据、脑成像数据对比。它的
  定位是**思想实验平台**——提供一个"可能世界"，观察它产生了什么。

**唯一承接原论文的，是两个公设**：
1. 认知状态是动态网络 `G(V, E, t)`；
2. 网络演化由能量最小化驱动。

在这两个公设之上，本项目添加的一切，都只是**观察**，不是**新假设**。

## 二、总体设计：六环逻辑链

本项目的所有数据、代码、结果，构成一条清晰的六环逻辑链：

```
一阶系统演化
    ↓ 产生压缩事件
【第 1 环】G2 关系图构建
    ↓ clique 建图
【第 2 环】压缩/迁移候选检测
    ↓ 统计
【第 3 环】客观指标（与原论文一致）
    ↓ 不动点检测（A/B/C 三方法）
【第 4 环】不动点与结构化定义
    ↓ 映射到连续空间
【第 5 环】四维概念空间（b, c, g1, g2）
    ↓ 凸性检验（自测 + 留出）
【第 6 环】与概念空间理论的对话
```

**每一环的输出，都是下一环的输入**。这不是一个并联的分析工具集，
是一个**嵌套的观察结构**：第 1 环把系统行为变成图，第 2 环在图上
检测，第 3 环验证统计规律，第 4 环把统计单元显式化，第 5 环把离散
标签换成连续坐标，第 6 环把坐标外推到外部理论。

下面逐环说明。

---

## 三、第 1 环：G2 关系图构建

### 3.1 这一环做什么

一阶系统 `universe.py` 运行 10000 次迭代后，会自然产生"概念压缩"
事件——每当它发现一组紧密关联的概念，就把它们作为一个单元记录下来。
每一次压缩是一条记录：`(center, {related_nodes})`。

本环把这些事件统计成一张**无向加权图 G2**：

- 节点 = 概念
- 边 = "这两个概念曾在一次压缩事件中一起出现"
- 边权 = 共现次数（clique 模式：一次压缩事件中所有无序对 +1，不做
  归一化）

**为什么是无向的**：单静态语境下，我们无法判断一次压缩是"中心 → 成员"
还是"成员 → 中心"。系统只记录"这些概念被压缩在一起过"这一事实。方向性
留待第 4 环从不动点派生。

**为什么是 clique 而非 star**：多粒度的压缩是系统的真实输出。一次 5 个
概念的压缩，产生 10 条边，而不是 4 条。这不是冗余，是保真。

### 3.2 这一环观察到了什么

以 51 规模为例：
- 939 条原始压缩事件 → 51 个节点、224 条边
- 边权最大值 341，均值 83.9

以 111 规模为例：
- 133 条原始压缩事件 → 111 个节点、66 条边
- 边权最大值 89，均值 27.4

**关键观察**：从 51 到 111，事件数下降 86%，边数下降 70%，但边权的
均值下降更多（68%）。这与原论文 §7.3 的"压缩密度随规模下降"一致——
系统在更大规模下只保留最必要的压缩。

|------|------|

| `results/compression_graph/compression_edges.csv` | 关系图的边表 |

## 四、第 2 环：压缩/迁移候选检测

### 4.1 这一环做什么

在 G2 上执行**与原论文完全一致**的两种检测：

**压缩检测**：对每个节点作为中心，取其 top-k 邻居构成簇，计算压缩势
Φ = 内部平均共现 / 外部平均共现。Φ 超过绝对阈值即记为一次压缩候选。

**迁移检测**：通过硬遍历 + 软遍历产生遍历历史，一条路径的平均共现
次数超过绝对阈值即记为一次迁移候选。

**为什么阈值是绝对值**：为了跨规模可比。不用百分位，不用相对阈值。
51 规模和 111 规模的阈值一样。

**为什么不做剪枝/去重**：搜索结果在完整图上进行，不做路径去重，不做
子集去重。现实中压缩本就是多粒度的，子集关系保留下来更贴近真实认知
状态。

### 4.2 这一环观察到了什么

以 111 规模为例：
- 压缩候选 63 个，迁移候选 0 个
- 迁移阈值扫描：阈值 50 时断崖归零

**关键观察**：111 规模的迁移数归零，与事件数骤降（133）一致。这不是
检测器的问题，是系统在极端复杂度下"不再产生可被检测的迁移"。

| `candidate_compressions.csv` | 压缩候选（center/cluster/size/phi） |
| `candidate_migrations.csv` | 迁移候选（start/end/path/score） |
| `threshold_scan_compression.csv` | 压缩阈值扫描 |
| `threshold_scan_migration.csv` | 迁移阈值扫描 |

## 五、第 3 环：客观指标（与原论文一致）

### 5.1 这一环做什么

本环是对第 1–2 环输出的**分布层面验证**。它复现原论文 §7.8 / §7.10
的客观指标，但**作用对象发生了位移**：原论文的 Zipf 是"中心节点频率"，
本项目的 Zipf 是"边共现频率"。这个位移是刻意的——它检验"关系图本身
是否也服从 Zipf"。

四类指标：

- **能量幂律**：`E(t) = at⁻ᵇ + c`，拟合能量下降曲线
- **Zipf（三类）**：边共现 / 中心频率 / 节点总频
- **Φ 分布**：压缩势的均值、标准差、分位数
- **阈值扫描**：压缩/迁移的敏感性

**为什么这些指标重要**：它们提供**独立于第 4–6 环的观察证据**。即使
第 4 环的不动点检测有问题，Zipf 和幂律依然是系统自发规律的证据。

### 5.2 这一环观察到了什么

- **能量幂律**：四个规模 R² > 0.9999，b 指数从 0.32 单调降到 0.18
- **边 Zipf**：斜率 −1.03 至 −1.18（与原论文 −1.36 有偏差，但同向）
- **Φ 分布**：均值从 1.82（51 规模）单调升到 2.63（111 规模），
  标准差从 0.23 升到 0.80
- **阈值扫描**：111 规模在压缩阈值 2.25 后归零，迁移阈值 50 处断崖

**关键观察**：Φ 均值随规模单调上升，与"大规模系统的边界更清晰、分化
更严重"的预期一致。Zipf 斜率略有偏差，可能源于"边共现"与"中心频率"
的统计对象不同，这个偏差本身是一个可报告的现象，不是缺陷。

| `power_law.csv` | 能量幂律拟合 |
| `zipf_edges.csv` / `zipf_centers.csv` / `zipf_node_totals.csv` | 三类 Zipf |
| `potential.csv` | Φ 分布统计 |
| `threshold_scan_{compression,migration}.csv` | 阈值扫描 |

## 六、第 4 环：不动点检测与结构化定义

### 6.1 这一环做什么

**这是整个项目的转折点**。前三环做的是"统计"，第 4 环开始**把统计单元
显式化**。

**不动点（fixpoint）** = 从压缩事件中识别出的**稳定单元**。它满足：
- 在事件中足够频繁（支持度高）
- 不可再分（没有更频繁的真子集）
- 成员的角色稳定（角色一致性高）

本环提供**三种独立的不动点检测方法**，共享同一个幂集枚举，但过滤规则
和参数完全独立：

| 方法 | 搜索空间 | 过滤规则 | 语义 |
|------|---------|---------|------|
| **A** | 幂集，`size = minsize..fp_max_itemset_size` | `support ≥ fp_min_support`，不做下界过滤、不做角色纯筛选 | 频繁项集闭包；`size=1` 是原子不动点候选，`size>1` 是原始事件层的高频整体候选 |
| **B** | 幂集 | `support ≥ lattice_min_support` + 下界过滤 | 最小频繁项集候选（不可再分） |
| **C** | 幂集 | `support ≥ role_min_support` + 下界过滤 + 角色一致性 ≥ `role_min_stability` | 角色纯候选（功能单一） |

**三种方法的语义要分开读**：

- **A**：在 `support ≥ fp_min_support` 下枚举 `size = minsize..fp_max_itemset_size` 的所有频繁项集。`minsize` 是枚举下界，不是唯一 size。A 不做下界过滤，也不做角色纯筛选。
  - A 的 `size=1` 输出是**原子不动点候选**：单概念、可写概念卡、对应后续概念图的基节点候选。
  - A 的 `size>1` 输出是**原始事件层的高频整体候选**：多概念组合，具备 `core/boundary/logic/energy/phi`，可以写成组合概念卡；但它必然包含频繁真子集，因此不是“不可再分原子”，而是“整体作为一个概念”的候选。
- **B**：在 `support ≥ lattice_min_support` 下保留“没有频繁真子集”的项集，即最小频繁项集。B 的 `size=1` 输出是单概念最小频繁单元候选。
- **C**：在 B 的基础上再要求成员平均角色一致性 ≥ `role_min_stability`，即角色纯候选。C 的 `size=1` 输出是单概念角色纯原子候选。

**集合关系**：只有在 support 阈值对齐时才有 C ⊂ B ⊂ A。当前三份 `fixpoints.json` 的 support 阈值不同（A 用 `fp_min_support`，B 用 `lattice_min_support`，C 用 `role_min_support`），不能直接用文件做集合包含验证。

**方法 A 的 `minsize` 语义**：不同 `minsize` 的 A 输出是同一频繁项集闭包按 size 下界的截断。`minsize=2` 去掉 size=1，保留 size≥2；`minsize=3` 去掉 size=1、2，保留 size≥3。同一 `size≥minsize` 项集的 `support`、`phi`、`boundary/logic/energy` 不随 `minsize` 改变。

**A 的独特观察量**：A 的 `size≥2` 项集携带 `phi = 内部平均共现 / 外部平均共现`；B/C 在 `minsize=1` 下 `phi=null`。因此 A 是唯一提供组合层压缩势分布的方法。

**关键设计：角色一致性**。原论文用的是位置稳定性 `S(x) = 1 − std(rank)/mean(rank)`，
这个公式在 `mean → 0` 时数值爆炸——任何"偶尔做成员"的概念，S 就崩到 0，
导致整组被否决。本项目换成：

```
role(x) = max(n_center, n_member) / (n_center + n_member)   ∈ [0.5, 1.0]
```

全中心 → 1.0；全成员 → 1.0；50/50 → 0.5。对称、有界、无数值爆炸。

### 6.2 结构化定义

每个不动点携带五个字段：

```json
{
  "core": ["不动点成员"],
  "boundary": ["指向核心的边缘概念"],
  "logic": {"边缘概念": 0.85},
  "energy": {"边缘概念": 0.31},
  "sources": ["支撑事件 ID"]
}
```

**这不是新机制，是定义形式本身**。原论文的定义形式是字符串
（`"牛顿定律": "物体运动的基本定律…"`），本项目把定义形式升级为结构。
"描述"不是系统执行的额外动作，是定义形式自带的属性。

### 6.3 这一环观察到了什么

以 51 规模、config_A 为例，方法 A 在不同 `minsize` 下的输出数量会变化，但这不是三种独立方法，而是同一闭包的不同 size 下界视图：

| 输出 | 含义 | 备注 |
|------|------|------|
| C | 角色纯的原子候选 | C/B 比 58.1% |
| B | 最小频繁单元候选 | — |
| A-minsize1 | 包含 `size=1` 原子不动点候选 + `size>1` 高频整体候选 | 完整闭包视图 |
| A-minsize2 | 只保留 `size≥2` 的高频整体候选 | 去掉 `size=1` |
| A-minsize3 | 只保留 `size≥3` 的高频整体候选 | 去掉 `size=1`、`2` |

**关键观察**：

- B 和 C 的 `minsize` 参数不参与主搜索空间，它们的主过滤是下界和角色纯；A 的 `minsize` 直接决定枚举下界。
- A 的 `size=1` 与 B 的 `size=1` 在语义上接近，但 A 不做下界过滤，所以 A 保留所有频繁项集；B 只保留下界项集。
- A 的 `size>1` 不是 B/C 的“更大粒度版本”，而是 B/C 因下界过滤而不会输出的组合层。它们携带 `phi`，是 A 独有的观察窗口。
- 在本仓库后续的第 5–6 环中，只使用 `minsize=1` 的 A/B/C 输出；`minsize>1` 的 A 输出保留为“原始事件层高频整体候选”的观察数据，不进入四维空间和凸性检验。
- 在 support 阈值对齐时，C ⊂ B 严格成立，差 1–16 个。

**关键观察（跨概念集）**：本项目引入**三套概念集**做对照：

- **config_A**（跨领域）：物理 + 数学 + CS + AI + 认知 + 神经 + 哲学 +
  经济 + 工程 + 原则，共 120 个概念
- **config_B**（CS 单领域）：算法 + 理论 + 语言 + 系统 + 网络 + 数据库 +
  AI + 软件工程 + 安全，共 120 个概念
- **config_C**（数学单领域）：逻辑 + 数系 + 代数 + 分析 + 几何 + 拓扑 +
  数论 + 应用数学，共 120 个概念

三套概念集的 C/B 比呈现三条不同的轨迹：
- A：单调上升（0.58 → 0.72 → 0.75 → 0.92）
- B：U 型（0.76 → 0.70 → 0.61 → 0.85）
- C：n 型（0.52 → 0.58 → 0.76 → 0.66）

**这不是噪声，是三种"概念加入顺序"的直接反映**：A 是跨域广度逐步拼接，
B 是子领域块顺序加入，C 是数学层级递进。

## 七、第 5 环：四维概念空间

### 7.1 这一环做什么

第 4 环输出的不动点是**离散标签**（"这个属于 C，那个属于 B−C"）。但
离散标签有一个根本问题：**边界处无法处理**。一个概念如果"有时做中心
有时做成员"，算 C 还是 B−C？阈值 0.7 和 0.71 有什么区别？

本环把离散标签换成**四维连续坐标**：

| 维度 | 含义 | 来源 |
|------|------|------|
| **b** | B 隶属度 = support（在压缩事件中的出现频率） | `raw_events` 统计 |
| **c** | C 隶属度 = 角色一致性（`max(n_center, n_member)/total`） | 同上 |
| **g1** | G1 能量图中的最小化程度（z 分） | `g1_export` |
| **g2** | G2 关系图中的中心性（z 分） | `raw_events` 重建 |

**这不是引入新维度，是把原有维度从"二元"展开为"连续"**。`in_B ∈ {True,
False}` 变成 `b ∈ [0, 1]`；`in_C ∈ {True, False}` 变成 `c ∈ [0.5, 1]`；
`g1 > 0 / g2 > 0` 变成保留 z 分。

**为什么 G1 用能量语义而不是拓扑语义**：G1 是近似全连接图。在这个图上
所有节点的度都接近 n−1，"度"和"中心性"没有区分度。节点的"重要性"不体现
在"连了多少边"，而体现在**边权能量被最小化到了什么程度**。所以 G1 的
正向信号从能量语义出发：节点平均边权（低 = 被频繁学习）、边权下降幅度
（大 = 学习得多）、遍历频率（高 = 被频繁激活）。

### 7.2 这一环观察到了什么

**最重要的观察：PC1 是 C 轴**。在 12 个 (config, scale) 组合上，第一
主成分始终是"角色收敛性"（方差 67–75%），第二主成分是 G1/G2 联合轴，
第四主成分是 B 轴。**这意味着：概念之间最大的差异来自角色一致性，而不是
结构稳定性。**

**B 是 PC4 的原因**：B 的方差小，不是因为 B 不重要，而是因为 B 是
"稀缺资源"——只有少数概念能成为最小频繁项集。这个稀缺本身就是"稳定核心
有限"的统计表达。

**三套概念集的耦合结构不同**：

| config | corr_b_c 随 scale | corr_b_g1 | corr_c_g2 |
|--------|------------------|-----------|-----------|
| A | 下降（0.72 → 0.35） | 高（0.3–0.67） | 负（−0.44） |
| B | 波动（0.81 → 0.56 → 0.95） | 趋近 0 | 负（−0.24） |
| C | 上升（0.50 → 0.97） | 低（0.1–0.27） | 近 0 |

**这不是三个"层"，是三种"通用层形成机制"**：A 靠能量（G1）捡起通用量，
B 靠关系图（G2），C 靠结构位置。

## 八、第 6 环：凸性检验（与概念空间理论的对话）

### 8.1 这一环做什么

前五环都在原论文框架内。第 6 环第一次**外推到外部理论**。

Gärdenfors 的概念空间理论主张"概念区域是凸的"。这个主张在文献中经历过
一个关键转向：从"必要约束"降格为"可检验预测"。Gärdenfors 本人明确说：
"凸性准则不是被提出来作为某个应用必然成立的东西，而是作为可检验的预测。
如果它被保证成立，它就没有任何经验内容。"

本项目把这个"可检验预测"落到四维概念空间上。**两种检验**：

**自测版**：用 expert 点建凸包，再用 expert 点测自己。输出：
- `expert_mean_convexity_ratio`（专家点对自己凸包的平均距离比）
- `general_outside_fraction`（general 点落在 expert 凸包外的比例）
- `volume_ratio`（expert 凸包体积 / 全体凸包体积）

**留出版**：一半 expert 点建凸包，另一半 + 全部 general 点测位置。
输出：
- `test_expert_inside_fraction`（留出的 expert 点落在训练凸包内的比例）
- `general_inside_fraction`（general 点落在训练凸包内的比例）
- `separation = test_inside − general_inside`

**为什么需要两版**：自测版的所有"近似 1.0"都是**凸包定义的自反性**（用
expert 建凸包、用 expert 测自己，必然 ≤ 1.0）。`general_outside_fraction = 1.0`
是**c 轴互斥**的必然。**只有留出版才是真检验**。

**为什么做 4D 和 3D 两模式**：4D 包含 c 维度，expert 和 general 沿 c 轴
互斥，凸包必然不相交。去掉 c 轴（3D 模式 `(b, g1, g2)`）后，两者在几何上
有重叠的可能，`general_inside` 第一次有机会不为 0。

### 8.2 这一环观察到了什么

**核心发现：自测版和留出版是两个宇宙**。

| 指标 | 自测版 | 留出版 |
|------|--------|--------|
| `expert_inside`（4D） | **≈ 1.0**（恒等） | **0.02 – 0.58** |
| `expert_inside`（3D） | **0.86 – 1.0** | **0.03 – 0.70** |
| `general_inside`（4D） | **0.0**（恒等） | **0.0**（仍恒等） |
| `general_inside`（3D） | **0.0** | **0.0 – 0.24** |
| `separation`（3D） | ≈ 0（自测无意义） | **0.02 – 0.38** |

**留出法的核心结论**：

- **专家层不严格凸**。留出一半后，另一半只有 20%–35% 落在训练凸包内。
  这不是"不凸"（不凸会是 ≈ 0），也不是"严格凸"（严格凸会是 ≈ 1），
  是**近似凸**或**星形近似**。
- **一般层部分混入凸包**。b=0.02/0.05 时约 20% 的 general 点落在 expert
  凸包内。这说明"专家 vs 一般"的二分在几何上**不是硬边界，而是渐变带**。
- **分离度 0.07–0.38**。按之前设定的 `separation > 0.5 强分离`，没有
  一组达到。但 `separation > 0.2` 在 b=0.0 时普遍成立。

**三套概念集的差异**：

| config | `separation`（3D, c_hi=0.65, b_lo=0.1） | 解释 |
|--------|---------------------------------------|------|
| 数学 | **0.151** | 有清晰家族相似结构，近似凸 |
| 跨领域 | 0.083 | 介于两者之间 |
| CS | **0.036** | 接口/桥接，不凸 |

**config_B（CS）在 c_hi=0.65, b_lo=0.02/0.05 出现负分离（−0.035, −0.048）**——
general 点比留出的 expert 点更容易落在凸包内。这是"CS 专家层在几何上完全
不凸"的直接信号。

### 8.3 与文献的对话

| 文献 | 实测对应 | 结论 |
|------|---------|------|
| **Gärdenfors**："凸性是可检验预测" | `test_inside` = 0.2–0.7，`separation` = 0.07–0.38 | 部分成立，不严格 |
| **Hernández-Conde**："凸性作为必要约束有问题" | 专家层不严格凸；20% 的 general 混入凸包 | 支持批评 |
| **Bechberger & Kühnberger**："用星形集合替代" | `separation` = 0.07–0.38 对应"有一个核心但不是严格凸" | 支持星形近似 |
| **Tětková et al.**："近似凸性普遍存在" | `test_inside` 0.2–0.7（不是 ≈ 1.0） | "近似"成立但强度有限 |
| **Jagiełło et al.**："概念场可以是非凸的" | config_B 的负分离（−0.05） | 直接支持非凸概念场 |

**综合定位**：**凸性作为近似成立，作为严格约束不成立**。这恰好落在
Gärdenfors "可检验预测"与 Hernández-Conde "必要约束批评"之间的那个
位置上。本项目不是"裁决"，是**把裁决的条件本身变成可观察、可复现、
有据可依的东西**。

### 9.1 G1 导出（`g1_export/`）

为第 5 环的 `g1_z` 提供数据。G1 是全连接能量图，节点的重要性不是"度"

### 9.2 六象限（`six_quadrant_results/`，历史）

六象限是本项目**方法论演进的中间产物**。它把每个概念按 `(G1 强/弱, G2 强/弱, in_B, in_C)`
分成六个离散象限（元概念/一般层/专家层/压缩产物/背景路径/背景目录）。

**它暴露了离散化的根本问题**：A@111 的 principles（变换、迭代、抽象）
既不在元概念象限（因为它们在 B/C 中），也不在专家层象限（因为 G2 为负），

第 5 环的四维连续坐标取代了六象限。保留是为了**展示方法论演进**——不是
保留一个"更好的方法"，是保留"从离散到连续的那一步"。

### 9.3 代数验证（`src/algebra/results/algebra/`）

对应原论文 §4–5 的群论部分的独立验证。含认知操作半群、Noether 对应、
轨道-稳定子定理、Lie 群演化的计算结果。**不在"关系图 → 不动点 → 四维
空间 → 凸性"这条逻辑链上**，是"代数结构验证"的平行支线。

## 十、可能的贡献

按"二阶观察层"的定位，本项目可能提供以下贡献：

### 10.1 形式化贡献：把"二阶观察"变成可算

原论文的"压缩/迁移"是**观察者的诊断工具**。本项目把这个诊断工具本身
形式化为数据对象：
- 压缩事件 → G2 关系图
- 关系图 → 压缩/迁移候选
- 事件序列 → 不动点
- 不动点 → 结构化定义
- 结构 → 四维坐标

**每一步都是可算的，每一步的输出都是可追溯的**。

### 10.2 方法论贡献：三种独立的不动点检测

原论文的位置稳定性 `1 − std/mean` 在数值上不稳定。本项目换成角色一致性，
并实现三种独立方法（A/B/C），三者关系在 support 阈值对齐时 C ⊂ B ⊂ A 可验证。**这不是"更好
的算法"，是"可比较的粒度谱系"**。A 的 `size=1` 是原子不动点候选，`size>1` 是原始事件层高频整体候选；B 是最小频繁项集候选；C 是角色纯候选。

### 10.3 经验贡献：三条 C/B 轨迹

三套概念集给出三条不同的 C/B 轨迹（A 单调升 / B U 型 / C n 型）。这
不是参数噪声，是**三种"概念加入顺序"的直接反映**。它提供了一种"用
C/B 比测量概念集结构"的方法。

### 10.4 理论贡献：从离散到连续

四维连续坐标取代六象限离散标签。PC1 = C 轴（方差 67–75%）是第一
次用数据回答"概念之间最大的差异是什么"。**这不是"更好的分类"，是
"意识到分类本身可能是多余的动作"**。

### 10.5 文献贡献：凸性假设的第一次可操作检验

留出法第一次把 Gärdenfors 的凸性假设从哲学争论变成可测量：`test_inside`
= 0.2–0.7，`separation` = 0.07–0.38。**结论不是"支持"或"反对"，是
"提供测量的条件谱系"——在什么条件下、对哪些点集、以什么强度，凸性成立。**

## 十一、局限与边界

### 11.1 概念集规模有限

120 个概念对比真实知识体系仍然很少。未来的扩展需要引入 WordNet、
ConceptNet 等知识库。

### 11.2 单静态语境

本项目完全在单静态语境下（与原论文一致）。多语境耦合属于后续工作。

### 11.3 凸性检验的局限性

- **4D 模式下的 `gof` 恒为 1.0 是定义产物**。这个结果没有经验内容。
- **b_lo=0.2 时样本太少**（n_expert 常 < 10），统计不稳定。
- **留出法只是"一个"检验方式**。其他方式（持续同调、核密度估计）可能
  给出不同的数字。

### 11.4 A@111 的结构断层

A@111 的 principles 拉平（n_events 从 897 骤降到 133，PC1 载荷混入 b）
不是自然轨迹的第四点，是结构断层。**不应与 51/71/91 直接比较**。

### 11.5 “抓重点”不是“概念生成”

本仓库做的是“抓重点”：从压缩事件中识别系统反复关注的稳定单元，并赋予结构化定义。`endo_concept` 这个模块名虽然叫“内生概念生成”，但在本仓库范围内，它仍然是抓重点——它输出的是“系统已形成的重点单元及其结构化定义”，不是另一个项目里的“让不动点成为新节点、构造更高层图、再压缩/迁移降层级”。

方法 A 的 `size=1` 是原子不动点候选；`size>1` 是原始事件层的高频整体候选。后者可以写成组合概念卡，是“整体作为一个概念”的候选，但它不是不可再分原子，也不是降层级后的高紧密度整体。**不要把 A 的 size>1 输出误读为“新概念已经生成”**——它是“哪些整体在原始事件中反复出现、值得进入后续降层级流程”的候选池。

## 十三、一句话总结

**本项目在《The Geometry, Algebra, and Dynamics of Cognition》的两个公设
之上，构建了一套二阶观察机制：把系统的压缩行为变成关系图（第 1 环），
在图上检测压缩/迁移（第 2 环），验证统计规律（第 3 环），提取不动点
（第 4 环），映射到四维连续空间（第 5 环），并用留出法对概念空间理论
的凸性假设做第一次可操作检验（第 6 环）。核心发现是：离散标签不够用，
连续坐标才是真实的；凸性作为近似成立，作为严格约束不成立；三套概念集
的 C/B 轨迹不同，对应三种通用层形成机制。这不是"验证原论文"，是
"把原论文的观察扩展到更深的层级"——从系统行为到关系图，从统计到结构，
从离散到连续，从内部框架到外部文献。方法 A 的 `size=1` 是原子不动点候选，
`size>1` 是原始事件层的高频整体候选；A 是唯一提供组合层 `phi` 分布的方法。**
